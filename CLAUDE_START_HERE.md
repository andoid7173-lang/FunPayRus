## Реальная архитектура

- Python 3.10+, базовое ядро — только stdlib. Ubuntu 24.04, systemd unit funpayrus.
- Код находится в /opt/funpayrus; секреты в /etc/funpayrus; SQLite и настройки в /var/lib/funpayrus.
- Один главный процесс Telegram long polling: bot/__main__.py + bot/telegram_api.py. Нельзя запускать второй getUpdates с тем же Bot Token.
- Role-based access: bot/settings.py, bot/commands.py. Роли owner, admin, viewer. Приватные Telegram-чаты.
- FunPay: bot/orders.py разбирает первую страницу https://funpay.com/orders/trade по Golden Key из окружения службы. Это read-only HTML parser, а не официальное API. Реальная полнота событий **не гарантируется**.
- В `main` **уже есть** интервал ~30 сек, пауза при 429, SQLite outbox для Telegram-уведомлений, уведомления об изменениях статусов, поиск /findorder, тест /testalert, /orders now и кнопка «⚡ Проверить сейчас».
- На первом успешном опросе старые заказы не оповещаются. Очередь гарантирует at-least-once; после падения может быть дубль.
- bot/plugins.py грузит встроенные плагины из plugins/; внешние выключены без явного разрешения. Незнакомый код нужно отдельно аудировать.
- В текущем main **нет** Microsoft Graph/Outlook, автовыдачи, отправки сообщений покупателям и Steam Guard.
- Никакой токен, Golden Key, OAuth-секрет или почтовый пароль из живого VPS в этот пакет не включён.
