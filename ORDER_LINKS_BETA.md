# 🐱 FunPay Rust v0.3.2b2 — ссылки на заказы в Telegram

Это тестовое обновление интерфейса мониторинга FunPay на чтение, без автовыдачи.

## Что добавлено

- В **новом Telegram-уведомлении о оплаченной продаже** появляется кнопка «🔗 Открыть заказ #ID». Она открывает страницу `https://funpay.com/orders/ID/` в браузере Telegram или в браузере устройства.
- В разделе **«📦 Заказы (тест)»** у последних пяти сохранённых заказов появляются отдельные кнопки перехода. Они доступны только владельцу и администраторам; наблюдатель (`viewer`) список заказов не видит.
- URL собирается только из строго проверенного ID заказа. Ссылки из HTML страницы FunPay, пользовательские URL, редиректы, ключи авторизации и токены не копируются в Telegram.
- Существующее хранилище SQLite, настройки, оповещения и режим опроса сохраняются. Новые зависимости не требуются.

## Как проверить

После установки ветки/релиза нажмите `/orders` либо дождитесь **новой** оплаченной продажи, если мониторинг и уведомления уже включены. Нажмите «🔗 Открыть заказ #…».

Для просмотра конкретной страницы FunPay браузеру может потребоваться авторизация в **вашем собственном аккаунте**. Telegram-бот не передаёт Golden Key, пароль или другие секреты в URL. Бот не открывает заказ от имени пользователя и не отправляет покупателю сообщений.

Обновление кода требует единоразового перезапуска Python-службы. После этого настройки `/orders` и подписки сохраняются, если не был выполнен скрипт полного сброса.

## Ограничения

- Неофициальный HTML мониторинг `/orders/trade` может перестать работать при изменении FunPay. Эта версия не проверяет покупку автоматически после нажатия ссылки.
- Ссылки корректны при сохранении стандартной структуры FunPay `/orders/<ID>/`. Сторонняя переадресация ботом не выполняется.
- Обнаружение оплаченных заказов и оповещения не гарантированы при сбоях сети/серверов, поэтому автоматическую выдачу не добавляем до отдельного аудита.

## Для разработчиков

`bot.orders.order_url()` отказывает для произвольных/небезопасных ID. `bot.orders.order_button()` возвращает только разрешённый Telegram URL-объект. `bot.commands.orders_menu()` формирует ссылки из локально сохранённых заказов. `bot.__main__.poll_orders_once()` присылает URL-кнопку при новом оплачённом заказе.

Тесты: `python3 -m unittest discover -s tests -v`, `python3 -m compileall -q bot plugins`, `bash -n install.sh scripts/*.sh`.
