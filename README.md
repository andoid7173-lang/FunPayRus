# 🐱 FunPay Rus

> **Статус:** v0.1.0 — рабочая Telegram-основа и пример плагина. **Подключение к FunPay, автовыдача и обработка заказов НЕ реализованы.** Эти возможности запланированы для будущих версий; не используйте текущую версию для настоящих продаж.

## Возможности v0.1.0

- Telegram-бот для одного администратора (`/start`, `/help`, `/status`, `/ping`).
- `/plugins` — список локально установленных плагинов.
- Пример плагина `/hello`, установленного из `plugins/hello`.
- Работа на собственном VPS через `systemd` с автоперезапуском.
- Хранение токена и ID администратора вне репозитория: `/etc/funpayrus/bot.env`.
- Простейший скрипт установки и подтверждаемого обновления.
- Без Golden Key, без передачи секретов автору, без платных серверов.

## Перед установкой

Ubuntu 22.04/24.04+ или совместимая система с systemd, доступ по SSH, sudo, интернет. Нужен собственный бот Telegram из **@BotFather**, а также цифровой Telegram ID администратора. Проверьте исходный код перед запуском. Установка меняет системные файлы и создаёт службу; запускайте её только на том VPS, где хотите установить бота.

## Установка на чистом VPS

```bash
sudo apt-get update
sudo apt-get install -y git python3
sudo git clone https://github.com/andoid7173-lang/FunPayRus.git /opt/funpayrus
cd /opt/funpayrus
sudo bash install.sh
```

При установке программа запросит Telegram-токен (ввод скрыт) и Telegram ID администратора. **Никогда не вставляйте токен в GitHub, README, Issues или сообщения посторонним.** Токен хранится только локально на вашем сервере в `/etc/funpayrus/bot.env` с ограниченными правами. Чтобы изменить настройки: `sudo bash install.sh --reconfigure`.

После установки откройте **своего бота** в Telegram и отправьте `/start`. Он будет отвечать только администратору, указанному при установке, и только в личном чате.

## Управление

```bash
sudo systemctl status funpayrus --no-pager
sudo systemctl restart funpayrus
sudo systemctl stop funpayrus
sudo systemctl start funpayrus
sudo journalctl -u funpayrus -n 40 --no-pager
```

## Обновление

```bash
cd /opt/funpayrus
sudo bash scripts/update.sh
```

Скрипт проверяет отсутствие локальных изменений, показывает новый коммит и спрашивает разрешение перед применением. Для будущих версий с базой данных добавим резервные копии и откат. **Не редактируйте файлы Git на VPS**, используйте Fork или свои плагины; текущий механизм обновления рассчитан на чистое дерево Git.

## Плагины

Первые плагины устанавливаются *вручную*: для личных плагинов на VPS используйте `/var/lib/funpayrus/plugins`, для примеров в репозитории — папку `plugins`. Личная папка плагинов не затрагивается Git-обновлениями. Смотрите [`plugins/README.md`](plugins/README.md). После установки перезапустите сервис, вызовите `/plugins` и `/hello`.

⚠️ **Плагины на Python — исполняемый код с доступом к правам и секретам бота.** Никогда не устанавливайте плагины неизвестного происхождения. В v0.1.0 нет загрузки ZIP через Telegram — такую функцию нужно проектировать с отдельными разрешениями и проверками.

## Разработка на ПК

На Windows можно клонировать репозиторий в любую папку на диске `D:` и редактировать проект через Codex, VS Code или другой редактор. Для запуска нужны `BOT_TOKEN` и `ADMIN_ID` в переменных окружения (локальные файлы с секретами должны оставаться вне Git).

Тесты без внешних библиотек:

```bash
python3 -m unittest discover -s tests -v
```
