# Плагины FunPay Rus

В версии `0.1.0` **доступна только ручная установка доверенных плагинов**:

1. На VPS разместите код в `/var/lib/funpayrus/plugins/ИМЯ_ПЛАГИНА/plugin.py` (рекомендуется, файлы сохраняются при обновлениях). Для разработки можно использовать `plugins/ИМЯ_ПЛАГИНА/plugin.py`.
2. Добавьте `manifest.json` с полями `name`, `version`, `command`, `enabled: true`.
3. Определите функцию `handle(args: str) -> str`.
4. Перезапустите службу `sudo systemctl restart funpayrus`.
5. В Telegram используйте `/plugins`, затем вызовите команду плагина.

Посмотрите рабочий пример `plugins/hello` (команда `/hello`).

**Внимание:** Python-плагины имеют права процесса бота и могут читать секреты из его окружения. Не устанавливайте случайные плагины. В следующих версиях будет отдельный менеджер разрешений и способ безопасного добавления плагинов через Telegram. Механизм безопасности приёма произвольных ZIP-файлов пока не реализован.
