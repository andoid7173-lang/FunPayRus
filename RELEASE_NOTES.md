# Тестовый выпуск v0.3.0b1 (4 ноября 2026)

Экспериментальная ветка `test/security-0.3.0b1` проекта FunPay Rus. **Не стабильный релиз и не подключение к реальным продажам.**

- Защита Telegram update offset между перезапусками (at-most-once, возможна потеря события при сбое после записи).
- Безопасное локальное хранение Golden Key в `/etc/funpayrus/funpay.env` и экспериментальная команда `/funpay` только для проверки авторизации без модификаций.
- Отключение сторонних Python-плагинов по умолчанию; без песочницы, вручную разрешённые плагины остаются привилегированным кодом.
- Дополнительные ограничения systemd; обновление с резервной копией и откатом Git-кода при ошибке.
- Тесты Python 3.10/3.12 в GitHub Actions, синтаксическая проверка Bash. Локальный тестовый набор без реального VPS/Golden Key.

Подробнее: [SECURITY_TEST_RELEASE.md](SECURITY_TEST_RELEASE.md).

# FunPay Rus v0.2.0 — предварительная версия

Ветка разработки: исправлена структура каталогов после загрузки через браузер и добавлено управление через кнопки Telegram.

## Добавлено
- Главное меню с кнопками: статус, плагины, проверка связи.
- Включение и отключение **локально установленных** плагинов по кнопке.
- Состояние плагинов сохраняется в `/var/lib/funpayrus/plugin-state.json`, вне Git-репозитория.
- Команды `/start`, `/menu`, `/help`, `/status`, `/plugins`, `/ping`.
- Исправлены пути модулей `bot/`, `plugins/`, `tests/`, `scripts/` и GitHub Actions.
- Тесты проверки доступа администратора и сохранения настроек.

## Важно
- **В основной ветке main по-прежнему v0.1.0.** Ветку v0.2 нужно проверить перед объединением.
- Установка на реальный VPS пока не проверялась.
- Загрузка ZIP и установка неизвестных Python-плагинов через Telegram НЕ реализована.
- Подключение FunPay, Golden Key и автовыдача НЕ реализованы.
- Пользовательские секреты хранятся только на его VPS.
