# v0.1.0 — первая версия

**Реализовано:** минимальный Telegram-бот с командами, локальная загрузка доверенных плагинов, интерактивный установщик, служба systemd, тесты, обновление через Git.

**Не реализовано:** интеграция с FunPay, автовыдача, реальная статистика магазина, установка плагинов через Telegram, автоматические бэкапы и откат.
